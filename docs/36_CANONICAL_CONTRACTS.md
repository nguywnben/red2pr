# Canonical contracts — P2 design, not generated API or running service

**Status:** Normative schema catalogue under ADR-033/035 except invariants ACCEPTED in ADR-009/025/030/031/032. Implemented portions and generated OpenAPI/client artifacts are recorded in [progress](23_PROGRESS.md); remaining proposed refinements retain their existing status. Companion: [API](07_API_CONTRACTS.md), [data](06_DATA_MODEL.md), [workflows](08_EVENTS_STATE_MACHINES.md), [permissions](30_ACCESS_CONTROL_MATRIX.md), [traceability](38_REQUIREMENTS_TRACEABILITY.md).

## Common types and wire rules
S-01 primitives: internal Id = UUID string (UUIDv7 proposed; opaque to clients); provider IDs = nonempty opaque string, never JS numeric coercion; Timestamp = RFC3339 UTC; Digest = lowercase SHA-256 hex (64 chars); Version = positive integer; Money = decimal string + ISO currency (no binary float); DurationMs = nonnegative integer. Internal IDs are not authorization. Text defaults max 4,096 characters, names 120, reason 1…1,000, URL 2,048, body JSON 1 MiB; log/artifact streaming uses dedicated capped paths. All fields below required unless suffixed ?; null is allowed only when explicitly stated. Enums reject unknown client inputs; external unknown statuses map to unknown with original redacted vendor value.

S-02 Resource common fields: id, workspace_id (absent only on explicit instance resources), version, created_at, updated_at; optional repository_id on repository-bound objects. Every repository FK must have same workspace. PATCH permits named fields only; unknown keys fail 422, including attempts to set role/status/proof through generic objects. Times and actors set by server. Retired API aliases never accepted silently.

S-03 Problem: type (stable URI), title, status, code, detail (safe text), correlation_id, errors? array of {field,code}; no stack/credential/provider body. Common outcomes: 400 malformed, 401 unauthenticated, 403 operation denied, 404 nonexistent OR inaccessible resource (consistent anti-enumeration), 409 version/state/idempotency conflict, 410 expired cursor/challenge, 412 If-Match failed, 422 validation, 429 limit with Retry-After, 503 dependency unavailable. An empty list is not an authorization failure.

S-04 Page<T>: items:T[], next_cursor:string|null, snapshot_at:Timestamp. limit integer 1…100 default25; cursor opaque signed with workspace, principal grants epoch, query hash and expiry; stable sort (created_at,id). Offset pagination not used for changing lists. Redacted search query max256; allowed filters/ordering documented per resource, never raw SQL.

S-05 ActionReceipt: operation_id, resource_id, state=accepted|running|succeeded|failed|unknown, correlation_id, status_url, result_id?, problem?. Async accepted returns202; operation polling/read never causes execution. Mutations use Idempotency-Key UUIDv7 (embedded timestamp age<=7days and future skew<=5min for first claim) and canonical request hash; atomically unique (principal,workspace,operation,key). Same key/different body→409; running duplicate→202 same operation; completed→same outcome. Store full response7days TARGET and retain logical-effect tombstone through retention plus maximum redelivery horizon; expired cached result does not authorize recreating effect. Once tombstone retention ends, the embedded key timestamp is outside the first-claim window and rejected (409 key_expired); authoritative unique logical effect keys still prevent a new timestamp key duplicating an existing publication. Remote idempotency cannot be assumed.

## Endpoint catalogue
All paths relative to /api/v1. W denotes /workspaces/{ws}; braces are resource IDs. Common S-03 errors apply to every row; lists use S-04 and mutable versioned resources ETag/If-Match. GET is side-effect free. Permission names resolve to [30](30_ACCESS_CONTROL_MATRIX.md). Every operation has audit (reads of sensitive artifacts as well); identity auth failures use rate-limited audit without secrets. Request/response column defines exact allowed request fields or named schema; read DTOs follow schemas above. Schema refinements are design review inputs, not implemented endpoints.

## S-19 events and SSE
Event fields: event_id, schema_version=1, type from doc08 registry, occurred_at, workspace_id (null only instance events), repository_id?,session_id?,aggregate_id,aggregate_version,correlation_id,causation_id?,payload. Payload is allowlisted per family:
provider connection {connection_id,status}; run {run_id,attempt_key,head_sha}; repair phase {repair_id,state,reason_code?}; reproduction/verification {repair_id,outcome,manifest_id}; approval {approval_id,status,expires_at?}; publication {publication_id,status}; remote {publication_id,head_sha,outcome}; worker {worker_id,status}; budget {budget_id,reason_code}; security/identity {target_id,reason_code}; operations {operation_id,status}; delivery {delivery_id,reason_code}. Resolve payload type from event type; unknown event version quarantined, not executed.
SSE id is opaque workspace event sequence cursor, not DB global offset; event name domain type, data redacted S-19. Delivery ordered per workspace sequence, no global cross-workspace order guarantee. Heartbeat15s TARGET; server replay window24h TARGET; expired/mismatched cursor→410 then REST snapshot + fresh cursor. Clients dedup event_id, apply aggregate_version or refetch on gap, never infer proof from an incomplete stream. Logout/revocation interrupts stream within target; slow consumer disconnected and resumes. Domain outbox retention is longer than SSE cache.

## S-20 typed agent tool protocol
Request {tool_call_id,repair_id,step_id,tool_name,arguments,context_digest}; response {tool_call_id,status=ok|denied|failed|pending,result?,operation_id?,problem?}. Tool policy revision/context grants bound by host, not model parameters. JSON Schema rejects extra properties, oversized payloads, invalid paths and tool names. Duplicate call ID with different args denied; repeated approved mutation yields prior receipt. Tools may run only in the pinned worktree/profile, never arbitrary shell chosen by model.

| Tool | Typed arguments → result | Allowed role / limit |
|---|---|---|
| read_file | {path,offset>=0,length<=65536} → {text,digest,truncated} | diagnosis/patch; read scope; no symlink escape or secret paths |
| search_repo | {query<=256,path_prefix,max_results<=100} → {matches[{path,line,excerpt}],truncated} | diagnosis/patch; bounded literal/validated search, timeout |
| read_log_excerpt | {artifact_id,offset,length<=65536} → {text,redaction_version,next_offset} | diagnosis/patch; only own session artifacts |
| read_commit_diff | {base_sha,head_sha,max_bytes<=262144} → {artifact_id,summary,truncated} | source pair from orchestrator allowlist |
| request_reproduction | {profile_id,command_ids[]} → ActionReceipt | diagnosis proposes; orchestrator authorizes; no caller argv/env |
| apply_patch | {base_sha,patch_artifact_id,expected_worktree_digest} → {patch_digest,changed_paths,integrity_outcome} | patch only; path/size policy before write, stop on rejected integrity |
| run_targeted_test | {profile_id,test_selection_id,patch_digest} → ActionReceipt | patch requests allowed tests, verifier chooses authoritative regression independently |
| get_execution_result | {operation_id} → trusted result reference | own repair scope; model cannot submit result |

No publish/merge/approve/rotate-secret/change-policy/network/host-shell tools. Schema repair of malformed model output max2 attempts within same budget; then abstain. Tool error is not proof of repo failure. Tool names from earlier API sketch run_targeted_tests/get_run_result are retired.

## S-21 worker and result contract
SandboxJobV1: schema_version,job_id,workspace_id,repository_id,repair_id,lease_epoch,capability_nonce,issued_at,expires_at,base_sha,source_archive_digest,patch_digest? (null baseline),profile_id/profile_revision,image_digest,command_ids[],resource_limits{cpu,memory_bytes,disk_bytes,pids,wall_seconds,output_bytes},network_policy_digest,artifact_upload_capability,expected_worker_trust_domain,supervisor_policy_digest. Commands resolve from immutable reviewed profile, not interpolated event/model strings. Source is archive scoped to SHA; read-fetch credentials terminate in trusted materializer, never guest git config/env.
ResultV1: job_id,lease_epoch,capability_nonce,worker_id,started_at,ended_at,exit_code|null,termination=exited|timeout|oom|cancelled|infrastructure_error,command_digest,image_digest,environment_digest,source_digest,patch_digest?,resource_usage,artifact_refs[{id,digest,size}],isolation_checks[],signer_key_id,signature. Missing exit code, timeout or infrastructure termination cannot pass tests.
mTLS worker identity + short-lived per-job capability scoped to heartbeat/result/upload; supervisor signing key outside guest. Control plane accepts one completion for active lease, validates hashes/schema/signature/time and trust_domain; stale lease→409, duplicate same result→prior receipt, different result same key→quarantine. Result endpoint internal /internal/v1/jobs/{id}/result, lease/heartbeat/cancel endpoints require worker capability and epoch. Upload capability can append only assigned artifacts, not read/list other jobs. Cancel ack includes process teardown and cleanup outcome; stale process cannot obtain new jobs.

## S-22 proof and audit
EvidenceManifestV1 contains workspace/repository/repair IDs, source/base/patched SHAs, diff digest, CI source run/jobs/attempt IDs, immutable profile+image+dependency lock+commands+environment digests, baseline and patched ResultV1 refs, failure fingerprint, fidelity grade/differences, regression selection/digest/results, integrity/security/policy outcomes, tool/model provenance (model ID, adapter version, request ID, redacted context hashes, usage), redaction revision, artifact digests, created_at, signer_key_id,signature.
Use canonical JSON serialization and domain-separated signature (algorithm proposed Ed25519); verifier rejects unknown key/algorithm/revoked-at-signing key/hash mismatch. Key rotation retains old public keys for old evidence; trust enrollment/revocation audited. Remote verification adds separate signed observation referencing published SHA and required-check set; never rewrites local manifest.
Audit append transaction includes previous hash; periodic signed checkpoint replicated to separately permissioned storage. Tampering with tail since last checkpoint remains a documented window; compromised signing supervisor can lie, so signing is integrity/provenance, not mathematical proof of execution truth. R-05/R-06 independent adversarial tests validate boundary. Report generation is template over verified manifest; LLM narrative clearly separated from gate verdict.

## Compatibility and acceptance
Versioned schema changes: additive optional fields within v1; required field/removal/semantics change v2 + migration and replay tests. Client unknown enums display unknown, never green. Control rejects unsupported worker protocol before leasing; N/N-1 overlap only for explicitly compatible versions. Deferred JSON/OpenAPI generation must reproduce this catalogue, with schema round-trip, adversarial extra-fields, cross-tenant FK, idempotency and event replay tests. IDs A/S are traced via features in [38](38_REQUIREMENTS_TRACEABILITY.md); none represent code already present.
